# Changelog

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Capsule Interference generator for rounded-rectangle contour-stack plotter studies.
- CONTRIBUTING.md
- This CHANGELOG

### Changed
- Retired the Java/Swing application and made the project web-only.
- Root build scripts now build the Vite web app only.
- Documentation now points contributors to `web/src/generators/` as the single generator implementation location.

## [1.0] — 2025

### Added
- 17 generative art algorithms (originally maintained as Java + Web dual implementations)
- Swing GUI with real-time preview and SVG export
- Web application (Vite + vanilla JS)
- Algorithms: Ribbon, Flow Fields, L-System, Reaction Diffusion, Harmonograph, Phyllotaxis, Strange Attractors, Circle Packing, Truchet Tiles, Twisted Moiré, Voronoi Ripples, Pipe Network, Parametric Grid, Magnetic Field, Fourier Series, Maze Generator, Spirograph
- Per-algorithm documentation (Readme_*.md)
- AGPL-3.0 license, GitHub Actions CI
