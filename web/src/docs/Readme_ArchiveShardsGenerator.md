# Archive Shards

Document fragments arranged by invisible metadata clusters and cross-reference links.

## Concept

This generator is a diagram-as-art study. Rectangular shards drift around metadata centers, then link to each other with faint dependency lines and machine-like marks.

## Parameters

Key controls: Shard Count, Cluster Count, Link Density, Fragmentation, Axis Bias.

Every preset is deterministic through `Seed`, and `Colors` controls how many plotter layers are emitted. `Stroke Width` only affects the browser preview and SVG stroke metadata; the real line weight comes from the pen.

## Plotter notes

Shard outlines, links, and metadata marks are separated. The generator is diagram-like rather than decorative; sparse presets plot cleaner.
