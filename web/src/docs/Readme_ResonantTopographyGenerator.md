# Resonant Topography

Topographic contour lines broken and warped by standing-wave resonance nodes.

## Concept

This generator blends the contour-map vocabulary with Chladni-like acoustic fields. A terrain surface is pulled by standing-wave nodes until the lines bend, thin, and break around quiet points.

## Parameters

Key controls: Contour Density, Wave Modes, Resonance Strength, Node Sharpness, Terrain Warp.

Every preset is deterministic through `Seed`, and `Colors` controls how many plotter layers are emitted. `Stroke Width` only affects the browser preview and SVG stroke metadata; the real line weight comes from the pen.

## Plotter notes

The contour layer carries the landscape. Nodes and break marks can be plotted in a lighter or contrasting pen to reveal the acoustic structure.
