# L-System Generator

This Java utility generates fractal patterns using L-Systems (Lindenmayer Systems) and exports them as SVG vector files. It's a dependency-free tool designed to create intricate, geometric art from a simple set of rules.

## Prerequisites

*   **Java 17+**

## Quick Start

1.  **Compile:**
    ```bash
    javac src/main/java/org/trostheide/generativeArt/LSystem.java
    ```

2.  **Run:**
    ```bash
    java -cp src/main/java org.trostheide.generativeArt.LSystem
    ```

3.  **View:**
    The program outputs `lsystem.svg` in the working directory.

## How It Works

The program uses a "turtle" graphics approach to interpret a string generated by the L-System rules.

1.  **Grammar Definition**:
    *   `AXIOM`: The starting string (e.g., "F").
    *   `RULES`: A map defining how characters are replaced (e.g., 'F' becomes "F+F-F-F+F").

2.  **String Expansion**:
    The axiom is iteratively expanded according to the rules for a specified number of `ITERATIONS`. Each iteration dramatically increases the string's complexity.

3.  **Turtle Interpretation**:
    The final string is processed character by character to draw the SVG path:
    *   `F`: Move forward and draw a line.
    *   `+`: Turn right by `ANGLE_DEGREES`.
    *   `-`: Turn left by `ANGLE_DEGREES`.

## Configuration

All parameters are located as static final variables in `LSystem.java`.

| Variable | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `ITERATIONS` | `int` | `4` | **Complexity.** Controls the level of detail. Higher values create more intricate fractals but increase processing time. |
| `AXIOM` | `String` | `"F"` | The initial state of the L-System. |
| `RULES` | `Map` | `{'F': "F+F-F-F+F"}` | The core logic for the fractal shape. Try changing this to create different patterns. |
| `ANGLE_DEGREES` | `double` | `90.0` | The angle the "turtle" turns for `+` and `-` commands. |
| `LINE_LENGTH` | `double` | `10.0` | The length of each segment drawn by the `F` command. |
| `INITIAL_X`, `INITIAL_Y` | `double` | `200`, `600` | The starting coordinates for the drawing. |

### Example L-System Rules

*   **Koch Snowflake Curve**: `AXIOM="F"`, `RULES={'F': "F+F-F-F+F"}`, `ANGLE=90`
*   **Dragon Curve**: `AXIOM="FX"`, `RULES={'X': "X+YF+", 'Y': "-FX-Y"}`, `ANGLE=90`
*   **Sierpinski Triangle**: `AXIOM="F-G-G"`, `RULES={'F': "F-G+F+G-F", 'G': "GG"}`, `ANGLE=120`

This L-System generator provides a powerful way to explore fractal geometry and create unique generative art, complementing the other two methods in this project.
